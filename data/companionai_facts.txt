CompanionAI was created by Dave Jones.
The application is built with Java 26 and Gradle.
It uses an embedded Tomcat web server on port 8080.
The knowledge base is stored in the data folder as plain text, PDF, and Word documents.
CompanionAI uses interchangeable local language-model providers, currently supporting Ollama and FastFlowLM.
